cezar module

cezar.analiza_czestotliwosci(napis: str) → int[źródło]

Analizuje tekst pod kątem występowania najczęstszych polskich liter.

Parametry:

napis (str) – Tekst do analizy.

Zwraca:

Liczba punktów (im więcej, tym bardziej tekst przypomina polski).

Typ zwracany:

int

cezar.cezar(napis: str, klucz: int) → str[źródło]

Szyfruje podany tekst za pomocą szyfru Cezara.

Funkcja ujednolica wielkość liter (zmienia na wielkie) i przesuwa litery alfabetu o podany klucz. Znaki niebędące literami pozostają bez zmian.

Parametry:

  • napis (str) – Tekst do zaszyfrowania.

  • klucz (int) – Przesunięcie (liczba całkowita).

Zwraca:

Zaszyfrowany tekst (wielkie litery).

Typ zwracany:

str

Wyrzuca:

TypeError – Jeśli typy argumentów są niepoprawne.
